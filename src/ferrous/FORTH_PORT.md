# Forth port status

The current user guide and availability information are maintained in
[WHOPPING FORTH for IMNOTWOPR](README_FORTH.md).

The port now has an interactive ACIA serial shell, a working RAM dictionary,
cold/warm startup, and error recovery. The old description of a non-interactive
port with unavailable terminal backends is obsolete. C64-specific device and
storage words remain unsupported.

See the dedicated README for build/run instructions, examples, available and
unavailable features, memory layout, Joshua snapshots, and validation status.
